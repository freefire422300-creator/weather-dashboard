# 🌤️ Weather Dashboard

یک داشبورد هواشناسی پیشرفته و رایگان که از API عمومی Open-Meteo استفاده می‌کند.

## ✨ ویژگی‌ها

✅ **بدون نیاز به API Key** - Open-Meteo رایگان و نامحدود
✅ **جستجوی شهرها** - جستجو فوری و سریع
✅ **دما و وضعیت هوا** - دمای فعلی، احساس دما، وضعیت
✅ **پیش‌بینی 7 روزه** - هر روز برای 7 روز بعد
✅ **پیش‌بینی هر ساعت** - 24 ساعت بعد
✅ **جزئیات آب و هوا** - رطوبت، سرعت باد، فشار، دید
✅ **طراحی مدرن** - رابط کاربری جذاب و حرفه‌ای
✅ **Responsive** - موبایل، تبلت، دسکتاپ
✅ **به‌روزرسانی لحظه‌ای** - داده‌های آب و هوای زنده
✅ **پشتیبانی فارسی** - رابط فارسی کامل

## 📚 API استفاده شده

### Open-Meteo
- **سایت**: https://open-meteo.com/
- **مزیت**: رایگان، بدون API Key، نامحدود
- **محدودیت**: 10,000 درخواست/روز برای IP واحد

### Endpoints:

**1. Geocoding API** - جستجوی شهرها
```
GET https://geocoding-api.open-meteo.com/v1/search
?name={city}&count=5&language=en&format=json
```

**2. Weather Forecast API** - داده‌های آب و هوا
```
GET https://api.open-meteo.com/v1/forecast
?latitude={lat}&longitude={lon}
&current={params}
&hourly={params}
&daily={params}
&temperature_unit=celsius
```

## 🎨 صفحات و بخش‌ها

### 1. **سرتیتر (Header)**
- نام داشبورد
- توضیح مختصر

### 2. **بخش جستجو (Search)**
- جستجوی شهرها
- پیشنهادهای لحظه‌ای
- انتخاب سریع

### 3. **کارت آب و هوای فعلی (Current Weather)**
- نام شهر و تاریخ
- دمای فعلی
- وضعیت هوا
- ایکون وضعیت

### 4. **جزئیات آب و هوا (Weather Details)**
- رطوبت
- سرعت باد
- فشار اتمسفری
- دید افق
- احتمال بارش
- احساس دما

### 5. **پیش‌بینی 7 روزه (7-Day Forecast)**
- نام روز
- ایکون وضعیت
- دمای بیشینه و کمینه
- احتمال بارش

### 6. **پیش‌بینی هر ساعت (Hourly Forecast)**
- ساعت
- دما
- وضعیت
- احتمال بارش

## 🌡️ واحدهای استفاده شده

| پارامتر | واحد |
|---------|------|
| دما | °C (سانتیگراد) |
| سرعت باد | km/h |
| بارش | mm |
| فشار | hPa |
| دید | km |
| رطوبت | % |

## 🎯 کد های آب و هوا

| کد | توضیح |
|----|----------|
| 0 | آسمان صاف ☀️ |
| 1-3 | ابری ☁️ |
| 45-48 | مه 🌫️ |
| 51-65 | بارش 🌧️ |
| 71-86 | برف ❄️ |
| 95-99 | گرج و برق ⚡ |
